# Contributing

Keep changes small and protocol-focused.

1. Add or update a failing test first.
2. Run `node --test tests/*.test.mjs`.
3. If translation behavior changes, run a live text, tool and vision probe.
4. Do not commit model weights, projectors, credentials, machine-specific
   Claude session files or user conversation transcripts.
5. Cite official Anthropic, Qwen or llama.cpp documentation for protocol and
   runtime claims.
